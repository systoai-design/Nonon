Do I need this?

No. To use NONON, download the Windows or Mac file. The source code is for people who want to look inside or build on it.

Check your download (optional)

The checksum (SHA-256) is a code worked out from the exact file we published. If your downloaded file gives the same code, it downloaded correctly and is the same file.

Windows (PowerShell)

Get-FileHash "$HOME\Downloads\NONON-setup.exe" -Algorithm SHA256

Mac (Terminal)

shasum -a 256 ~/Downloads/NONON.dmg

Before you install

  • NONON runs on Windows 10 or 11 (64-bit) and Macs with Apple silicon (M1 or later). There is no phone, Linux or Intel Mac version.
  • Aim for 8 GB of memory at least. 16 GB is better. These are targets we are testing, not promises.
  • See what works today, and what leaves your computer on the privacy page.

Finish everyday work with your own files. The AI works on your computer, so it keeps working when the internet doesn't.
